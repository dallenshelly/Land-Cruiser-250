## 🚀 Quick Start

### Prerequisites
- Python 3.6 or higher
- Modern web browser with WebGL support

### Installation & Running

1. **Clone or download** this repository
2. **Navigate to the project directory**
3. **Run the Python webserver:**

```bash
python run.py
```

The server will automatically:
- Start a local HTTP server on port 8000
- Launch your default browser
- Display the Land Cruiser 250 3D demo

### Manual Access
If the browser doesn't open automatically, navigate to:
```
http://localhost:8000
```

## 🎨 Visual Highlights

- **Dark Theme**: Deep charcoal and black backgrounds (#0a0a0a, #111111)
- **Gold Accents**: Metallic gold gradients (#FFD700, #DAA520) on highlights
- **Glass Effects**: Semi-transparent panels with `backdrop-filter: blur(10px)`
- **Dynamic Lighting**: Three-point lighting with golden rim highlights

## 🛠️ Technical Details

- **3D Engine**: Three.js r128
- **Renderer**: WebGL 2.0 with fallback to WebGL 1.0
- **Model Format**: GLTF/GLB with PBR materials
- **Animations**: Smooth camera orbits and auto-rotate option
- **Performance**: Optimized for 60 FPS on modern hardware
